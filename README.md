# Ruffing Game

Структура: `www/index.html` + модули `www/js/*.js` (config, scene, shaders, city, graphics, audio, ui, controls, stairs, game). Свои модели: `www/models/person.glb`, `car.glb`.

Локально: `npm install && npm run dev`.
APK: пуш в `main`, вкладка Actions, Build APK, Artifacts, `ruffing-game-apk`.
